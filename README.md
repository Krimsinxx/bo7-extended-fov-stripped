# bo7-extended-fov-stripped
A stripped down version of my [BO7 Zombies Extended FOV Mod](https://github.com/Krimsinxx/bo7-extended-fov/tree/main)

## Install
Download and copy `extended_fov.gsc` from the [latest](https://github.com/Krimsinxx/bo7-extended-fov-stripped/releases/tag/v1) release into `cod25\kronos\custom_scripts`

### OR

Download the code as a zip and extract the `extended_fov` folder into `cod25\kronos\mods`
